# you know what it is

website for my music group that debuted at offkai expo gen 5 and slayed it
basically i'm just tryna make us look more official so we can get more gigs, and having a dope website with a real domain name makes you look hella official

i didn't want to use react AT ALL because i write a ton of react for work already and this is just a single webpage so i felt like there wouldn't be any need for react, but when i got to the grid of band members, i thought to myself how much more quickly i'd be able to get it going if i could map a list of react components. i was right ahahaha

also, dist is the directory containing the actual stuff that gets beamed up to the web and that you, the end user, will see on your device. i have to vite build to wind up with my bundle which goes into dist, then i deploy the github pages site from dist as a submodule. that's that sh-t they don't teach you in web development 101. that's that sh-t they teach you in web development 102 lol
